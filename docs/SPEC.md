# 마음마을 탐험대 개발 기준 명세

문서 버전: 2026-10-10 / 범위: 기본형 10편·단계형 5편, 총 15편 / 상태: 구현 기준. 원본 상세 명세: `생활기술_교육앱_상세개발명세서_v1.0.docx`(이 저장소 밖에서 작성됨). 이 파일만으로 개발을 진행할 수 있도록 핵심 규칙과 콘텐츠를 옮겼다.

## 1. 요구의 출처와 우선순위

- **확정 요구**: 초등 2~3학년 느린학습자 대상. 목표는 상황에서 할 행동을 배우는 것. 감정 알아차리기·감정 선택 학습 제외. 미니게임은 `행동 선택하기`, `좋은 행동 나누기` 두 종류. 2026-10-10 사용자가 순서 맞추기 대신 분류/결과 예측 중 하나를 요청했고, 이번 6-1f에서는 분류하기를 채택했다. 자기관리에는 다른 사람, 특히 선생님이 말하는 도중 할 말이 생겼을 때 잠깐 멈추고 차례를 기다린 뒤 말하기 포함. (2026-10-10 사용자 결정으로 이 B02는 `학교 — 교실에서 지내기`로 옮겼다. 다루는 행동은 같다.) 4개 영역·12개 MVP 콘텐츠, 진도/달성률 표시, 아동 안전 배려.
- **이번 구현의 작업 기본값**: 현재 저장소의 React/TypeScript/Vite PWA를 유지하고 오프라인 중심으로 개편한다. 아래 에피소드의 세부 문구·수치·저장 형식·화면 배치는 상세 명세의 제안에서 출발한 작업 기준이다. 교육자·아동 시험 후 바꿀 수 있으며 변경 시 `DECISIONS.md`에 이유를 남긴다.
- **이전 자료**: `PRD-v1.md`, `APP_PROPOSAL.md`, 기존 감정 중심 JSON/화면, 기존 `docs/` 기록은 이전 제품의 구현과 이력을 설명한다. 이 문서와 상충하는 학습 규칙은 적용하지 않는다. 첨부 UI의 감정 선택 화면도 이전 시안이다.

### 1.1 2026-10-10 3차 개선의 확정 요구 (8-1)

아래 조항은 첨부 「마음잇다 앱 3차 개선」 요청에 따른 최신 예외다. 이후 절의 12편·14편 수치와 과거의 감정 활동 제외 원칙보다 이 범위에서 우선한다. 과거 원고와 결정 이력은 보존한다.

- 현재 장소는 생활 정원 2편·우리 집 3편·학교 6편·도움 쉼터 4편, 총 15편이다. 5개 사회정서영역은 기존 장소를 대체하지 않고 대표 이야기의 태그로 표시한다.
- 단계형 대표 이야기: C04 자기인식(감정·신체 반응 탐색과 자유 연결), B02 자기관리(생각 탐색·행동 선택·순서), C01 관계인식(생각 구분), C05 관계관리(관계 회복 순서), D04 마음건강관리(감정 탐색·대처 선택·표현/도움 요청·말하기 연습). 나머지 10편은 행동 선택+좋은 행동 나누기를 유지한다.
- D04의 감정 선택에는 정답/오답이 없다. 대처 선택은 친구에게 말하기와 처음부터 선생님께 도움 요청하기 모두 인정한다. 표현 미션의 각 보기에는 설명과 대안을 보여 주고, 권장 답을 강제하지 않고 다음 상황으로 갈 수 있다. 힌트·재선택·다시 하기를 지원한다.
- 연습 문장은 화면에 항상 표시한다. 문장 듣기·다시 듣기는 선택 사항이고 읽기만으로도 완료 가능하다. 녹음·음성 인식·평가는 추가하지 않는다. 화면 이탈/미션 초기화 때 재생을 종료하며, 음성이 불가능하면 문자 안내로 계속한다.
- 단계형 저장은 편별 `maumlink.steps.mvp-v1.<id>`를 사용한다. 콘텐츠 버전·단계/보기 참조·완료 요건을 검사한다. 구버전/손상된 기록은 자동 덮어쓰기 없이 명시 재시작을 안내한다. 기존 완료 ID와 옛 감정 앱 저장은 유지한다.
- 완료 수/진행률은 실제 색인의 15편 기준이며, 재학습해도 중복 증가하지 않는다. 공통 완료 화면의 3개 이동 버튼을 유지한다.

## 2. 제품 경계와 성공 기준

학습 한 편은 짧은 상황을 보고 적절한 행동을 선택한 뒤, 같은 상황의 행동 카드를 두 바구니로 분류하고, 이유와 다음에 쓸 말을 확인하는 과정이다. 정답 하나만 암기시키기보다 안전한 대안과 상대의 선택을 인정한다. 진도는 시도 횟수나 점수가 아닌 완료한 에피소드 수로 보여 준다. 앱은 진단·치료·감정 평가를 표방하지 않는다.

MVP는 아동용 익명 로컬 프로필, 4개 영역/12편, 두 활동, 피드백, 이어하기, 완료/진도, 선택형 읽어주기와 접근성, 보호자·교사용 설정을 포함한다. 계정·서버 동기화·채팅·광고·인앱 결제·공개 순위·기본 분석 수집은 범위 밖이다.

## 4. 학습 게임과 피드백

### 4.1 행동 선택하기 (`behavior_choice`)

상황과 한 문장의 질문을 먼저 제공한다. 아동은 카드 하나를 고르고 `확인`을 눌러 제출한다. 오터치 방지를 위해 자동 제출하지 않는다. 정답 판정은 `acceptedChoiceIds` 배열을 사용한다. 맥락상 안전한 다른 방법이 있으면 함께 허용한다. 오답 후 카드를 섞거나 선택 자체를 처벌하지 않는다. 첫 실패에는 이유+작은 힌트, 다음 실패에는 더 구체적인 행동 모델을 제시한다. 힌트는 언제든 볼 수 있다. 지원받아 해결해도 완료할 수 있다.

### 4.2 좋은 행동 나누기 (`behavior_sort`)

2026-10-10 사용자 요청에 따라 기존 순서 맞추기를 대체한다. 상황별 기본 4장(스키마 허용 4~6장)을 `이렇게 해요 👍`와 `다시 생각해요 🤔`로 나눈다. 2026-10-10 후속 사용자 요청(6-1g)에 따라 바구니를 카드 위에 배치하고, 마우스·터치·펜으로 카드를 끌어 바구니에 놓을 수 있다. 스크롤 중에도 상단 바구니를 고정하고, 끄는 카드와 놓을 바구니를 강조한다. 바구니 밖에 놓기·Escape·터치 취소는 기존 분류를 보존한다. 드래그를 원하지 않으면 카드와 바구니를 차례로 누르거나 키보드로 조작할 수 있다. 카드 위치는 고정하고 배치한 바구니를 글자로 표시한다. 이미 배치한 카드도 다시 끌거나 눌러 바꿀 수 있다. 시간제한·흔들림·실패 효과음은 없다.

모든 카드를 나눈 뒤 `나눈 내용 확인하기`로 명시 제출한다. 맞지 않는 배치는 카드별 이유/대안을 안내하고 나머지 배치는 유지한다. 힌트·예시는 언제든 열 수 있다. 두 번째 오답 확인에는 예시를 열며, `예시대로 나누기` 뒤 직접 확인해도 완료할 수 있다. 전부 맞으면 `다음`으로 돌아보기를 연다. 카드·바구니는 버튼으로 키보드/터치를 지원하고 선택/배치 상태와 피드백을 보조기술에 제공한다.

판정은 `sorting.cards[].category`(`do`/`rethink`)를 사용한다. 쉬기·도움 요청·거절·위험 시 즉시 알리기를 맥락에 맞게 인정한다. 최신 원고는 `content/episodes/*.json`의 `sorting`, 사람이 읽는 배치표는 [SORTING-CONTENT.md](./SORTING-CONTENT.md)다. 옛 `sequence` 데이터와 아래 순서 원고는 이력으로 보존하며 새 화면에서는 사용하지 않는다. 결과 예측은 이번 범위 밖이다.

### 4.3 피드백 원칙

`무엇을 했는지 → 왜 도움이 되는지 → 다음에 할 수 있는 일`을 1~3개의 짧은 문장으로 말한다. “틀렸어”, “나쁜 아이”, 점수·실패음·연속 출석 압박·시간제한·경쟁 순위는 쓰지 않는다. 안전을 위한 즉시 도움 요청, 쉬기, 거절, 비언어적 도움 요청은 문제의 좁은 정답 때문에 부정하지 않는다. 위험·괴롭힘 장면은 실제 경험을 재현하도록 요구하지 않는다. 읽어주기는 반복할 수 있으나 화면 이동 시 중단하고, 자동재생 제한·음성 오류 시 텍스트만으로 진행 가능해야 한다.

## 5. 영역과 MVP 12편

영역(장소)은 `생활 정원 — 밖에서 친구와 놀기`, `우리 집 — 집에서 스스로 하기`, `학교 — 교실에서 지내기`, `도움 쉼터 — 쉬고 도움받기`다(ID는 A·B·C·D 유지). 처음에는 `생활 속 상황 대처 / 자기관리 / 대인관계 / 안전하게 쉬고 도움받기`의 주제별 4영역에 3편씩이었다. 2026-10-10 사용자 결정으로 장소에 맞게 다시 묶었다: 생활 정원 C01·C03, 우리 집 B01·A02·B03, 학교 A01·B02·C02·A03, 도움 쉼터 D01~D03(2·3·4·3편, 총 12편). 2026-10-10 1차 개선 요청으로 학교에 C04 「친구들이 내 발표를 놀렸어요」를 더해 총 13편(2·3·5·3)이 되었고, B02 문구는 요청서 내용으로 바뀌었다(DECISIONS 참고). 2차 개선 요청으로 C01을 「친구들과 함께 놀고 싶어요」로 교체하고 학교에 C05 「나는 장난이었는데 친구는 속상해요」를 더해 총 14편(2·3·6·3)이 되었다. C01·C05는 단계형 이야기(`format: "steps"`)로, 정답 없는 감정·생각 고르기와 생각 구분하기/순서 맞추기 미션을 쓴다(사용자 결정, D-NEW-01 예외). 저장 기록을 지키기 위해 이야기 ID는 바꾸지 않는다. A02·B03·C01·C03은 새 장소에 맞게 배경 문구를 고쳤고(콘텐츠 버전 2), 최신 문구는 `content/episodes/*.json`이 기준이다. 아래 5.1은 처음 작업 원고다. 모든 아동용 문구는 출시 전에 교육자와 아동 관찰로 검토한다. `B02`가 첫 종단 구현 대상이다.

### 5.1 편별 작업 원고

아래 문구는 초기 개발 초안 이력이다. 2026-10-10 이후 후속 활동은 §4.2와 `sorting` 데이터를 따르며 아래의 순서 카드 원고는 새 경로에 노출하지 않는다. 보기 순서와 인물 표현은 실제 화면에서 검토하되, 안전 예외를 유지한다.

#### A01 잘 모르겠어요 — 학교로 이동

- 목표: 이해되지 않는 안내를 다시 설명해 달라고 요청한다.
- 상황: 선생님이 만들기 방법을 알려 주었어요. 무엇을 먼저 할지 잘 모르겠어요. 어떻게 하면 좋을까요?
- 행동 선택 보기:
  1. “처음에 무엇을 해요?”라고 물어봐요. **(현재 장면의 허용 답)**
  2. 잘 모르지만 옆 친구 것을 그대로 가져와요.
  3. 모른다는 말을 하지 않고 종이를 버려요.
- 적절한 행동 피드백: 다시 물어봤어요. 설명을 듣고 첫 번째 일을 할 수 있어요.
- 보기 2 피드백: 친구 물건을 가져오기보다 무엇을 할지 물어봐요.
- 보기 3 피드백: 종이를 버리기 전에 다시 설명해 달라고 말할 수 있어요.
- 순서 카드 정답 예: 선생님에게 도움을 요청해요. → 처음 할 일을 다시 들어요. → 알려 준 첫 번째 일을 해요.
- 힌트: 무엇을 해야 하는지 알려 줄 사람을 찾아요.
- 생활 적용: 안내가 모호한 놀이 방법을 성인이 제시하고 아동이 다시 묻는 말을 연습한다.
- 안전·대안: 말로 묻기 어렵다면 도움 카드를 가리키는 방법도 인정한다. 상대가 다른 사람과 대화 중이면 급하지 않은 질문은 B02의 차례 규칙을 적용한다.

#### A02 실수했어요 — 우리 집으로 이동, 배경을 내 방으로 수정

- 목표: 실수를 숨기지 않고 안전하게 알린 뒤 정리를 돕는다.
- 상황: 책상에서 종이컵의 물을 조금 쏟았어요. 가까이에 전기 기기나 깨진 물건은 없어요. 어떻게 하면 좋을까요?
- 행동 선택 보기:
  1. 모른 척하고 다른 곳으로 가요.
  2. 선생님에게 알리고 닦는 것을 도와요. **(현재 장면의 허용 답)**
  3. 다른 친구가 쏟았다고 말해요.
- 적절한 행동 피드백: 물을 쏟았다고 알렸어요. 안전하게 닦으면 책상을 다시 쓸 수 있어요.
- 보기 1 피드백: 물이 남으면 다른 사람이 젖을 수 있어요. 쏟았다고 알려요.
- 보기 3 피드백: 다른 친구 탓으로 말하기보다 실제 일어난 일을 알려요.
- 순서 카드 정답 예: 물을 쏟았다고 알려요. → 어른에게 닦을 것을 받아요. → 안전한 곳의 물을 함께 닦아요.
- 힌트: 함께 정리할 수 있도록 일어난 일을 알려요.
- 생활 적용: 빈 컵과 마른 천으로 알리기와 정리하기 역할놀이를 한다.
- 안전·대안: 뜨거운 물, 유리, 전기가 있으면 만지지 않고 떨어져 어른에게 알린다. 위험한 것을 직접 치우도록 유도하지 않는다.

#### A03 하던 일이 잘 안돼요 — 학교로 이동

- 목표: 작업이 잘되지 않을 때 잠깐 멈추고 구체적인 도움을 요청한다.
- 상황: 종이 접기를 하는데 모서리가 잘 맞지 않아요. 몇 번 해도 어려워요. 어떻게 하면 좋을까요?
- 행동 선택 보기:
  1. 종이를 친구 쪽으로 던져요.
  2. 친구가 완성한 것을 가져와요.
  3. 손을 잠깐 멈추고 접는 방법을 물어봐요. **(현재 장면의 허용 답)**
- 적절한 행동 피드백: 잠깐 멈추고 도움을 요청했어요. 방법을 보고 다시 해 볼 수 있어요.
- 보기 1 피드백: 종이를 던지면 다른 사람에게 닿을 수 있어요. 손을 멈춰요.
- 보기 2 피드백: 친구 작품 대신 내 종이를 어떻게 접을지 물어봐요.
- 순서 카드 정답 예: 종이를 내려놓고 잠깐 멈춰요. → 어려운 부분을 가리키며 물어봐요. → 알려 준 방법으로 다시 해 봐요.
- 힌트: 어느 부분이 어려운지 보여 주면 도움받기 쉬워요.
- 생활 적용: 조립이나 퍼즐에서 어려운 부분을 가리키고 “여기를 도와주세요”를 연습한다.
- 안전·대안: 반드시 끝까지 해내도록 압박하지 않는다. 계속 어려우면 쉬기나 활동 바꾸기를 성인과 정할 수 있다.

#### B01 내 가방을 챙겨요 — 우리 집

- 목표: 그림 준비물 목록을 확인하고 물건을 넣은 뒤 확인한다.
- 상황: 내일 학교에 가져갈 준비물 그림이 있어요. 공책과 필통을 챙기려고 해요. 무엇을 먼저 할까요?
- 행동 선택 보기:
  1. 그림 목록에서 챙길 물건을 확인해요. **(현재 장면의 허용 답)**
  2. 눈에 보이는 물건을 모두 가방에 넣어요.
  3. 준비물을 보지 않고 가방을 닫아요.
- 적절한 행동 피드백: 목록을 먼저 봤어요. 필요한 물건을 찾아 넣을 수 있어요.
- 보기 2 피드백: 모든 물건 대신 목록에 있는 준비물을 찾아요.
- 보기 3 피드백: 가방을 닫기 전에 필요한 물건이 있는지 확인해요.
- 순서 카드 정답 예: 그림 준비물 목록을 봐요. → 목록의 물건을 가방에 넣어요. → 목록과 가방 속 물건을 확인해요.
- 힌트: 필요한 물건을 알려 주는 그림을 찾아요.
- 생활 적용: 집에서 쓰는 실제 준비물 2개와 그림 목록으로 연습한다.
- 안전·대안: 준비물이 없으면 보호자에게 알린다. 없는 물건을 아동의 잘못으로 표현하지 않고 반드시 구매하도록 유도하지 않는다.

#### B02 나도 할 말이 있어요 — 학교로 이동

- 목표: 다른 사람이 말할 때 잠깐 멈추고 차례를 기다린 뒤 말한다. 이 행동 목표는 확정 요구다.
- 상황: 선생님이 설명하고 있어요. 급하지 않은 할 말이 생겼어요. 어떻게 하면 좋을까요?
- 행동 선택 보기:
  1. 선생님 말이 끝나기 전에 바로 말해요.
  2. 잠깐 멈추고 손을 들어 차례를 기다려요. **(현재 장면의 허용 답)**
  3. 선생님 옷을 계속 잡아당겨요.
- 적절한 행동 피드백: 잠깐 멈추고 차례를 기다렸어요. 내 차례가 되면 말할 수 있어요.
- 보기 1 피드백: 지금 말하면 설명이 끊길 수 있어요. 잠깐 멈춰요.
- 보기 3 피드백: 옷을 잡아당기기보다 손을 들고 차례를 기다려요.
- 순서 카드 정답 예: 잠깐 멈추고 들어요. → 손을 들고 차례를 기다려요. → 내 차례가 되면 말해요.
- 힌트: 지금 누가 말하고 있는지 살펴봐요.
- 생활 적용: 선생님 외 상황도 연습한다. 가족이나 친구에게는 “잠깐 멈추기 → 상대의 말이 끝나기를 기다리기 → 내 말 하기” 원고를 사용한다.
- 안전·대안: 다치거나 위험하거나 긴급하게 도움이 필요하면 기다리지 않고 바로 알린다. 눈 맞춤이나 고정된 자세를 기다림의 필수 조건으로 채점하지 않는다.

#### B03 다음 활동을 준비해요 — 우리 집, 배경을 집(블록 정리→저녁)으로 수정

- 목표: 활동 전환 안내에 따라 사용한 물건을 정리하고 다음 활동을 준비한다.
- 상황: 그림 그리기가 끝나고 책 읽기 시간이 되었어요. 책상에 색연필이 있어요. 무엇을 하면 좋을까요?
- 행동 선택 보기:
  1. 색연필을 바닥에 놓아요.
  2. 친구 책상으로 색연필을 밀어요.
  3. 색연필을 정리하고 읽을 책을 꺼내요. **(현재 장면의 허용 답)**
- 적절한 행동 피드백: 사용한 물건을 정리했어요. 책을 놓을 자리가 생겼어요.
- 보기 1 피드백: 바닥에 놓으면 밟을 수 있어요. 정해진 통에 넣어요.
- 보기 2 피드백: 친구 자리 대신 색연필 통에 정리해요.
- 순서 카드 정답 예: 하던 그리기를 멈춰요. → 색연필을 정해진 통에 넣어요. → 읽을 책을 꺼내요.
- 힌트: 다음 활동을 할 자리를 먼저 만들어요.
- 생활 적용: 활동 전환 전 그림 일정표로 미리 알리고 같은 세 단계를 연습한다.
- 안전·대안: 갑작스러운 전환을 강요하지 않는다. 더 필요한 시간을 요청하는 행동은 오답으로 일반화하지 않는다.

#### C01 나도 같이 놀고 싶어요 — 생활 정원으로 이동, 놀이터 모래 놀이로 수정

- 목표: 놀이 참여 의사를 말하고 상대의 답을 들은 뒤 행동한다.
- 상황: 친구들이 블록 놀이를 해요. 나도 함께하고 싶어요. 어떻게 하면 좋을까요?
- 행동 선택 보기:
  1. “나도 같이 해도 돼?”라고 물어봐요. **(현재 장면의 허용 답)**
  2. 친구의 블록을 바로 가져와요.
  3. 친구가 만든 것을 밀어 버려요.
- 적절한 행동 피드백: 같이 놀아도 되는지 물어봤어요. 친구의 답을 듣고 정할 수 있어요.
- 보기 2 피드백: 먼저 물어보고 친구의 답을 들어요.
- 보기 3 피드백: 만든 것을 밀면 무너질 수 있어요. 함께하고 싶다고 말해요.
- 순서 카드 정답 예: 같이 놀아도 되는지 물어봐요. → 친구의 답을 들어요. → 좋다고 하면 함께 놀이해요.
- 힌트: 함께하고 싶다는 말을 먼저 전해요.
- 생활 적용: 친구 역할의 성인이 참여 가능과 지금은 어려움 두 답을 번갈아 말한다. 거절 뒤 다른 놀이를 고르는 방법도 설명한다.
- 안전·대안: 항상 받아 주거나 거절을 참아야 한다고 가르치지 않는다. 반복적인 배제나 괴롭힘이 있으면 어른의 도움을 받을 수 있다.

#### C02 친구 물건을 쓰고 싶어요 — 학교

- 목표: 물건 사용 허락을 구하고 사용 후 돌려준다.
- 상황: 친구의 빨간 색연필을 잠깐 쓰고 싶어요. 아직 물어보지 않았어요. 무엇을 먼저 할까요?
- 행동 선택 보기:
  1. 친구가 보지 않을 때 가져와요.
  2. “빨간 색연필 빌려도 돼?”라고 물어봐요. **(현재 장면의 허용 답)**
  3. 내 물건이라고 말하며 가져와요.
- 적절한 행동 피드백: 빌려도 되는지 물어봤어요. 친구가 괜찮다고 하면 사용할 수 있어요.
- 보기 1 피드백: 친구 물건은 먼저 물어보고 답을 들어요.
- 보기 3 피드백: 친구의 물건임을 알고 빌려 달라고 말해요.
- 순서 카드 정답 예: 빌려도 되는지 물어봐요. → 좋다고 하면 사용해요. → 다 쓰면 고맙다고 말하고 돌려줘요.
- 힌트: 물건의 주인에게 먼저 물어봐요.
- 생활 적용: 빌려주기 싫다는 답도 연습하고 다른 색이나 내 물건을 사용하는 대안을 알려 준다.
- 안전·대안: 반대로 아동도 자신의 물건을 빌려주지 않을 수 있다. 거절을 무례함이나 실패로 채점하지 않는다.

#### C03 서로 다른 놀이를 하고 싶어요 — 생활 정원으로 이동, 그네·미끄럼틀로 수정

- 목표: 상대의 제안을 듣고 번갈아 하는 방법을 제안한다.
- 상황: 나는 공놀이를, 친구는 블록 놀이를 하고 싶어요. 둘 다 할 시간이 있어요. 어떻게 말하면 좋을까요?
- 행동 선택 보기:
  1. “내가 하고 싶은 것만 해야 해.”
  2. “네 놀이는 하면 안 돼.”
  3. “블록을 하고 공놀이도 할까?” **(현재 장면의 허용 답)**
- 적절한 행동 피드백: 두 놀이를 해 보는 방법을 말했어요. 친구와 함께 정할 수 있어요.
- 보기 1 피드백: 친구가 하고 싶은 것도 듣고 방법을 찾아봐요.
- 보기 2 피드백: 친구 놀이를 막기보다 함께할 방법을 말해요.
- 순서 카드 정답 예: 친구가 하고 싶은 놀이를 들어요. → 번갈아 하자고 제안해요. → 둘 다 좋다고 한 순서로 놀이해요.
- 힌트: 두 사람이 원하는 놀이를 모두 할 방법을 찾아요.
- 생활 적용: “내 놀이부터 해도 될까?” 같은 다른 협의 문장도 적절한 행동으로 인정한다.
- 안전·대안: 서로 동의하지 않으면 따로 놀거나 어른의 도움을 받을 수 있다. 늘 양보하는 행동만 정답으로 만들지 않는다.

#### D01 잠깐 쉬고 싶어요 — 도움 쉼터

- 목표: 활동을 이어가기 어려울 때 쉬겠다고 알리고 정해진 안전한 곳에서 쉰다.
- 상황: 교실에서 활동을 계속하기 어려워 잠깐 쉬고 싶어요. 선생님과 정한 쉬는 자리가 있어요. 어떻게 할까요?
- 행동 선택 보기:
  1. 선생님에게 쉬고 싶다고 알려요. **(현재 장면의 허용 답)**
  2. 아무 말 없이 학교 밖으로 나가요.
  3. 친구의 활동 도구를 밀어요.
- 적절한 행동 피드백: 쉬고 싶다고 알렸어요. 정해진 안전한 곳에서 쉴 수 있어요.
- 보기 2 피드백: 아무도 모르게 나가기보다 가까운 어른에게 알려요.
- 보기 3 피드백: 도구를 밀기보다 쉬고 싶다는 말을 전해요.
- 순서 카드 정답 예: 쉬고 싶다고 알려요. → 정해진 안전한 자리에서 쉬어요. → 돌아갈 준비가 되면 선생님과 이야기해요.
- 힌트: 쉬고 싶다는 것을 알려 줄 사람을 찾아요.
- 생활 적용: 말하기 또는 쉬기 카드를 보여 주는 방법을 연습한다. 쉬는 시간은 성인과 아동이 상황에 맞게 정한다.
- 안전·대안: 감정을 고르거나 몸의 신호를 정답으로 맞히게 하지 않는다. 복귀 시간 제한이나 참기 점수는 두지 않는다.

#### D02 그만해 주세요 — 도움 쉼터

- 목표: 원하지 않는 행동을 멈춰 달라고 말하고 계속되면 도움을 요청한다.
- 상황: 친구가 내 모자를 자꾸 잡아당겨요. 나는 그만했으면 해요. 지금 말할 수 있는 상황이에요. 어떻게 할까요?
- 행동 선택 보기:
  1. 나도 친구 옷을 잡아당겨요.
  2. “그만해 줘”라고 말하고 어른에게 도움을 요청해요. **(현재 장면의 허용 답)**
  3. 싫어도 계속 해도 된다고 말해요.
- 적절한 행동 피드백: 멈춰 달라고 말할 수 있어요. 계속되면 어른에게 도움을 요청해요.
- 보기 1 피드백: 함께 잡아당기면 다칠 수 있어요. 거리를 두고 도움을 요청해요.
- 보기 3 피드백: 싫은 행동을 허락하지 않아도 돼요. 도움을 받을 수 있어요.
- 순서 카드 정답 예: “그만해 줘”라고 말해요. → 멈추지 않으면 안전하게 거리를 둬요. → 가까운 선생님에게 알려요.
- 힌트: 내가 원하지 않는 행동은 멈춰 달라고 말할 수 있어요.
- 생활 적용: 모자를 실제 잡아당기는 재현 없이 인형이나 그림으로 말하기와 도움 요청을 연습한다.
- 안전·대안: 위험하거나 말하기 어려우면 첫 단계를 생략하고 바로 피하거나 도움을 요청해도 된다. 고정 순서는 이 문항의 한정된 연습 예이며 안전 행동을 오답으로 만들지 않는다.

#### D03 어디로 가야 할까요 — 도움 쉼터

- 목표: 학교에서 가야 할 곳을 모르면 혼자 찾으러 나가지 않고 학교 어른에게 도움을 요청한다.
- 상황: 학교 복도에서 이동할 교실이 어디인지 모르겠어요. 가까운 교무실에 선생님이 보여요. 어떻게 할까요?
- 행동 선택 보기:
  1. 학교 밖으로 나가서 찾아봐요.
  2. 모르는 사람을 따라가요.
  3. 교무실 선생님에게 갈 곳을 물어봐요. **(현재 장면의 허용 답)**
- 적절한 행동 피드백: 학교 선생님에게 물어봤어요. 안내를 받고 갈 수 있어요.
- 보기 1 피드백: 학교 밖으로 나가기보다 가까운 선생님에게 물어봐요.
- 보기 2 피드백: 모르는 사람을 따라가지 않고 학교 선생님에게 알려요.
- 순서 카드 정답 예: 복도의 안전한 곳에 멈춰요. → 가까운 교무실 선생님에게 물어봐요. → 선생님의 안내에 따라 이동해요.
- 힌트: 지금 학교에서 도움을 줄 수 있는 어른을 찾아요.
- 생활 적용: 실제 학교의 지정 도움 장소를 보호자나 교사와 확인한다. 실제 위치는 앱에 업로드하지 않는다.
- 안전·대안: 학교라는 맥락으로 한정한다. 모든 어른이나 낯선 사람을 무조건 따라가라는 일반 규칙으로 확장하지 않는다.


## 6. 진도와 저장

- 팩 ID `mvp-v1`, 총 12편을 고정한다. `completedEpisodeIds`의 고유 ID 수만 분자이며 `달성률 = round(완료 수 / 12 × 100)`으로 계산한다. 표시값: 0→0%, 1→8%, 3→25%, 4→33%, 6→50%, 11→92%, 12→100%.
- 한 편의 두 활동이 각각 `정답으로 해결` 또는 `모델 확인 후 해결` 상태이고 완료 화면에 도달하면 완료를 한 번 기록한다. 재방문·재생·중복 제출은 증가/취소를 일으키지 않는다. 첫 완료 시각과 최근 활동은 완료 수와 별도 저장한다.
- `첫 시도 정답`, `힌트/다시 시도 후 해결`, `모델 보고 해결`은 학습 지원 정보로만 구분한다. 힌트·음성·큰 글씨 사용은 불이익이나 실패로 계산하지 않는다.
- 진행 세션에는 팩/콘텐츠 버전, 편 ID, 단계, 선택·분류 중 상태, 시도 횟수, 힌트 표시와 중복 제출 방지 ID를 둔다. 재시작하면 정확한 장면으로 돌아오고 음성은 자동 재생하지 않는다. 쓰기 실패를 성공으로 표시하지 않는다. 손상 저장은 설명과 복구 선택을 제공한다.
- 옛 `maumlink.progress.v1`의 4개 시나리오 완료를 새 12편 완료로 개수나 영역만 보고 자동 전환하지 않는다. 이전 데이터를 보존하고 새 팩의 키로 별도 시작한다. 명시적 일대일 검증 규칙 없이는 마이그레이션하지 않는다.

## 7. 콘텐츠 데이터 계약

아래는 논리 구조다. 실행 스키마는 `src/content/behaviorSchema.ts`, 로더는 `src/content/behaviorEpisode.ts`다. JSON에는 `choice`, `sorting` 필드를 두며 옛 `sequence`는 이력으로 보존한다. `src/content/schema.ts`의 감정 스키마는 과거 구현 전용이다.

```ts
type ContentPack = { id: 'mvp-v1'; schemaVersion: number; episodeIds: string[] }
type Episode = {
  id: string; version: number; domainId: 'A' | 'B' | 'C' | 'D'
  title: string; objective: string
  situation: { text: string; imageId: string; alt: string; audioId?: string }
  activities: [ChoiceActivity, SortActivity]
  takeaway: string; safetyNote: string
  review: { state: 'draft' | 'reviewed' | 'published' | 'retired'; reviewedVersion?: number }
}
type ChoiceActivity = {
  kind: 'behavior_choice'; prompt: string
  choices: { id: string; text: string; feedback: string }[]
  acceptedChoiceIds: string[]; hint: string; modelChoiceId: string
}
type SortActivity = {
  kind: 'behavior_sort'; prompt: string
  cards: { id: string; text: string; category: 'do' | 'rethink'; feedback: string }[]
  hint: string; feedback: string
}
type ActivityResult = { outcome: 'independent' | 'supported' | 'modeled'; attempts: number; helpUsed: boolean }
type Progress = { packId: string; completedEpisodeIds: string[]; firstCompletedAt: Record<string, string> }
```

콘텐츠 검증: 4개 영역·12개 고유 ID·각 편 활동 두 종류 각각 한 개, 선택/분류 카드 ID 중복 없음, 정답 ID는 실제 선택만 참조, 분류 카드는 4~6장이고 두 범주가 모두 있으며 카드마다 범주와 구체적 피드백 필수, 필수 대체 텍스트와 그림/오디오 대체 경로, 검토 버전 일치, 미검토 원고 배포 금지. 아동 화면의 감정 퀴즈 필드와 옛 감정·생각 단계 연결을 배포 경로에서 제거한다. 고정된 정답이 상황의 안전한 예외를 부정하는지 교육 검토한다.

## 9. 개인정보·아동 안전

실명, 학교/위치, 얼굴 사진, 감정 일기, 녹음, 연락처를 기본 수집하지 않는다. 아바타는 로컬 무작위 ID로 식별한다. 어른 설정과 초기화는 아동 학습 화면에서 우발 실행되지 않게 분리한다. 데이터 삭제 시 영향과 복구 불가를 명확히 설명한다. 안전 장면은 “도움받을 수 있는 가까운 어른”을 맥락에 맞춰 표현한다. 긴급한 위험·부상·괴롭힘에서 B02 차례 기다리기를 적용하지 않는다. 기존 음성 파일은 새 문장과 일치하고 사용권을 확인한 경우에만 재사용한다. 앱 안에서 음성 생성 서비스나 모델 API를 호출하지 않는다.

## 10. 개발 순서와 품질 문턱

구체적 작업 번호·상태·검증 기록은 `PLAN.md`. 순서는 현행 코드/저장 구조 확인 → B02 데이터와 전체 흐름 구현 → 11편 확장 → UI/접근성/음성 정리 → 실기기·교육 검토다. 첫 기능 마일스톤은 B02가 정상/오답/힌트/모델/중단/재시작/중복 완료를 모두 통과하는 것. 옛 감정용 검사 `validate:final-content`는 원본 PDF 전사 검사이므로 새 12편의 검토·검증으로 대체하기 전에는 새 제품의 출시 게이트로 해석하지 않는다. 시각 검토에서 모바일 세로, 태블릿 가로, 200% 확대, 키보드/스크린리더, 오프라인, 저장 오류를 포함한다. 교육자 검토 없이 아동 대상 효과나 안전성을 확정했다고 표시하지 않는다.
