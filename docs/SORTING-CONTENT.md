# 좋은 행동 나누기 콘텐츠 초안

2026-10-10 / 작업 6-1f / 교육자·아동 검토 전. 실행 원고와 카드별 설명은 `content/episodes/*.json`의 버전 있는 `sorting` 필드가 기준이다.

첫 번째 행동 선택의 정답 확인 뒤, 각 이야기의 상황을 유지하여 행동 카드 4장을 두 바구니로 분류한다. 사람을 좋은/나쁜 사람으로 평가하지 않는다. 쉬기·도움 요청·거절·안전한 거리 두기는 정당한 행동으로 인정한다. 장면의 맥락 없이 늘 옳거나 틀린 행동으로 일반화하지 않는다. 위험 행동은 문자로만 제시하고 재현·시연하지 않는다.

카드를 위 바구니로 끌어 놓거나 카드와 바구니를 차례로 누른다(6-1g). 이미 나눈 카드도 다시 눌러 바꿀 수 있고, 모든 카드를 나눈 뒤 명시적으로 확인한다. 다시 생각할 배치가 있으면 카드별 이유/대안을 보여 주며 나머지 배치는 유지한다. 힌트와 예시는 언제든 사용할 수 있고, 예시로 나누어도 직접 확인한 뒤 완료할 수 있다. 시간제한·점수·실패 효과음·흔들림은 없다. 드래그 취소나 바구니 밖에 놓기는 기존 분류를 유지한다.
