# 탐험 지도 홈 화면 — 구현 가이드

`index.html`은 장소를 클릭하기 직전까지의 홈 화면입니다. 클릭 후 로직은 기존 코드에 이미 있으므로 `onPlaceSelect(place)`에 연결만 하면 됩니다.

## 구성
- 헤더: 제목 + 소리 토글 + 설정 버튼
- 인사 카드: 캐릭터(48×48) + 인사말
- 진행 카드: 완료 수 / 전체 수, 진행 막대, 퍼센트 (`PLACES[].done`에서 자동 계산)
- 지도: 배경 `assets/map-bg.png` 위에 흰색 35%를 덮음. 2열 그리드
  - 생활 정원(위, 가운데) → 우리 집 / 학교(가운데 좌우) → 도움 쉼터(아래, 가운데)
  - 장소 1개 = 제목(그림 위, 살짝 겹침) + 그림 + 알약형 이름표(설명 + 진행 점 + n/3)

## 연결할 곳
1. `PLACES`: 실제 진행 데이터로 교체 (`done` 배열 = 에피소드별 완료 여부)
2. `onPlaceSelect(place)`: 기존 클릭 후 로직 호출
3. `btnSound`, `btnSettings`: 기존 소리/설정 로직 연결
4. 캐릭터 이미지: `.avatar` 안에 `<img>` 추가

## 에셋 (assets/)
- `map-bg.png`: 지도 배경
- `playground.png`: 생활 정원
- `home.png`: 우리 집
- `classroom.png`: 학교
- `tree.png`: 도움 쉼터

장소 그림 4장은 원본 PNG에 체크무늬가 그려져 있어서 지우고 투명 배경으로 다시 저장한 파일입니다.

## 디자인 수치
- 텍스트: Noto Sans KR, `word-break: keep-all`, 이름·설명은 `nowrap`
- 주요 색: 글자 `#13314a` / `#1d2b3a`, 강조 `#0f7a5a`, 막대 바탕 `#dfe6ea`
- 그림 높이: 생활 정원 140px, 우리 집·학교 150px, 도움 쉼터 160px
- 이름표: `border-radius: 999px`, 흰색 82%, 그림 아래에 22px 겹침
