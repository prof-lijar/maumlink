# 마음잇다 (Maum:Link)

초등 2~3학년 느린학습자가 일상 속 사회적 상황에서 **어떻게 행동하고 말할지** 연습하는 사회정서교육 앱입니다. 아이는 탐험 지도에서 장소를 고르고, 짧은 이야기 속 상황을 보며 행동을 고르고, 친구와 대화하고, 좋은 행동을 정리합니다.

- 계정·서버·분석 없이 기기 안에서만 동작하는 오프라인 우선 웹앱(PWA)이며, 같은 빌드를 Android 앱으로도 묶습니다.
- 점수·시간 제한·별점이 없습니다. 실수에 수치심을 주지 않고, 쉬기·도움 요청·거절·위험할 때 바로 알리기를 좋은 행동으로 다룹니다.
- **현재 상태:** 15편 모두 교육자 검토 전 초안(`draft`)입니다. 출시 전에 교육자 검토와 아동 관찰이 필요합니다.

## 학습 흐름

```
시작 → 아바타 고르기 → 탐험 지도(장소 4곳) → 장소별 이야기 목록 → 이야기 → 마무리
```

이야기 안의 활동은 편마다 다릅니다. 기본 형태는 **상황 보기 → 행동 선택 → 좋은 행동 나누기**이고, 일부 이야기는 감정·생각 탐색, 친구와 대화, 순서 맞추기 같은 단계를 더 가집니다.

- 모든 이야기는 처음부터 열려 있고, 순서와 상관없이 할 수 있습니다.
- 모든 화면에 **이전으로**가 있고, 중간에 나가도 진행 상태가 저장되어 이어서 할 수 있습니다.
- 상황별 미션은 **건너뛰어도** 이야기를 마칠 수 있습니다.
- 마무리 화면은 모든 이야기가 같습니다: "잘했어요! 오늘도 새로운 방법을 배웠어요." + 이야기별 마무리 문장 + 다시 연습하기 / 다른 이야기 만나기 / 탐험 지도로 돌아가기.

## 활동 종류

| 활동 | 하는 일 | 판정 |
| --- | --- | --- |
| 행동 선택 | 보기 3개 중 할 행동을 고르고 "선택 확인하기" | 정답이 여러 개일 수 있음. 다른 보기는 결과를 설명하고 다시 고르게 함. 힌트·예시 제공 |
| 감정·생각 고르기 | 그때의 마음이나 이유를 고름. "잘 모르겠어요"도 있음 | 정답 없음. 고른 보기의 설명 + 공통 마무리 |
| 좋은 행동 나누기 | 행동 카드 4장을 👍 이렇게 해요 / ✋ 안돼요 칸에 끌어 놓거나 눌러서 담기 | 다 담은 뒤 확인. 다시 볼 카드에 이유 표시. 힌트·예시·다시 해보기 |
| 친구와 대화하기 | 내 차례에 말 3개 중 하나를 고르면 친구가 "입력 중" 뒤에 답함 | 좋은 말은 칭찬과 함께 대화가 이어짐. 다른 말은 친구 반응 + 도움말 후 다시 말하기 |
| 순서 맞추기 | 행동 카드 3장을 할 순서대로 놓기(놓은 카드는 눌러서 빼기) | 허용 순서 여러 개 가능. 다른 순서면 배치 유지 + 힌트 |
| 마음–몸 신호 연결 | 감정 카드와 몸의 반응 카드를 선으로 연결 | 모든 연결을 인정하고 설명 |
| 말 고르기·말하기 연습 | 이어지는 두 상황에서 할 말 고르기 → 도움 요청 문장 듣기·따라 말하기 | 권장 표현 안내. 듣기 없이 읽기만으로도 완료 |

모든 활동은 터치·마우스·키보드로 할 수 있고, 드래그는 필수가 아닙니다.

## 실행하기

Node 20 이상과 pnpm 10이 필요합니다.

```bash
pnpm install
pnpm dev                 # http://localhost:5173
pnpm build               # 콘텐츠 검사 → 타입 검사 → 웹 빌드(dist/)
pnpm preview             # 빌드 결과 미리보기 http://localhost:4173
```

### 검사

```bash
pnpm validate            # 콘텐츠(15편) 스키마·참조 검사
pnpm typecheck
pnpm test                # 단위 검사
pnpm lint
npx playwright test --config playwright.behavior.config.ts   # 현재 흐름 브라우저 검사(시스템 Chrome)
```

`pnpm test:e2e`와 `pnpm validate:final-content`는 이전 감정 중심 버전용 검사라서 현재 흐름의 통과 근거로 쓰지 않습니다.

### Android

```bash
pnpm build:native        # 네이티브용 웹 빌드 + cap sync android
pnpm android:apk         # 디버그 APK (JDK 21 필요, 예: Android Studio 내장 JBR)
adb install -r android/app/build/outputs/apk/debug/app-debug.apk
```

appId(`com.maumlink.app`)와 앱 이름은 임시값입니다. Android WebView에는 브라우저 음성 합성이 없어서, 말하기 연습의 "문장 듣기"는 글자 안내로 대신합니다.

```

  screens/               지도(Home), 목록(DomainEpisodes), 기본형 게임(BehaviorGame), 단계형 게임(StepEpisodeGame)
  screens/missions/      재사용 미션 — Conversation, SequenceOrder, EmotionBodyMatch, ExpressionChoice, PerspectiveSort
```

## 콘텐츠 고치기

문구와 보기는 화면 코드가 아니라 `content/`의 JSON에 있습니다.

1. `content/episodes/<ID>.json`을 고치고, 내용이 바뀌면 `version`을 1 올립니다. 그러면 예전 내용으로 하다 만 진행은 안내 화면을 거쳐 새로 시작합니다.
2. 목록에 보이는 제목·요약은 `content/episode-index.json`도 함께 고칩니다.
3. `pnpm validate`로 검사합니다.
4. 제목용 글꼴(Jua)은 쓰인 글자만 담고 있으므로, 새 글자가 들어가면 `pnpm fonts`로 다시 만듭니다.

이야기는 두 형식이 있습니다.
- **기본형:** `choice` + `sorting` + 선택 `conversation`
- **단계형(`"format": "steps"`):** `steps` 배열에 `reflect`, `choice`, `conversation`, `sequence`, `emotion_body_match`, `expression_choice`, `note` 등을 순서대로 둡니다.

## 저장과 개인정보

이름이나 개인정보를 받지 않습니다. 아바타 선택, 설정, 완료 기록, 하다 만 진행은 그 기기의 브라우저 저장소에만 남습니다.

| 저장 내용 | 키 |
| --- | --- |
| 완료 기록 | `maumlink.progress.mvp-v2` |
| 아바타 | `maumlink.profile.mvp-v1` |
| 설정 | `maumlink.settings.v1` |
| 이야기별 진행 | `maumlink.session.mvp-v1.<ID>`, `maumlink.steps.mvp-v1.<ID>` |

이전 버전의 완료 기록(`mvp-v1`)은 지우지 않고 따로 남아 있습니다.
