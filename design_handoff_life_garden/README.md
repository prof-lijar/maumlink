# Handoff: 마음마을 탐험대 – 생활 정원 에피소드 흐름 리디자인

## Overview
아동용 사회성 학습 앱 "마음마을 탐험대"의 '생활 정원' 영역 화면 리디자인입니다. 에피소드 목록 → 상황 질문(선택지) → 좋은 선택 피드백 → 순서 맞추기 미니게임 → 순서 완료 → 활동 완료로 이어지는 6개 화면입니다. 기존 기능/문구는 유지하고 시각 스타일(따뜻한 크림·하늘색 배경, 오렌지 CTA, 둥근 흰 카드, 동글한 제목 폰트)과 순서 맞추기 상호작용을 개선했습니다.

## About the Design Files
`design/` 폴더의 파일은 **HTML로 만든 디자인 레퍼런스(프로토타입)** 입니다. 그대로 배포할 코드가 아닙니다. 대상 코드베이스의 기존 환경(React, Vue, Flutter, 네이티브 등)과 기존 패턴·라이브러리로 **이 디자인을 재구현**하세요. 코드베이스가 없다면 프로젝트에 가장 적합한 프레임워크를 골라 구현하세요.
- `마음마을 생활정원.dc.html` 을 브라우저로 열면(같은 폴더의 `support.js` 필요, 로컬 서버 권장) 상단 탭으로 6개 화면을 오가며 동작을 확인할 수 있습니다.
- 파일 안의 인라인 스타일 값이 정확한 기준값입니다. 하단 `class Component` 에 상태 로직이 있습니다.

## Fidelity
**High-fidelity.** 색상·타이포·간격·라운드·그림자·상호작용이 최종안입니다. 픽셀 단위로 맞춰 재현하세요. 기준 뷰포트 폭 390px(모바일).

## Interactions & Behavior
- 화면 전환 시 스크롤 맨 위로, 화면별 상태 초기화
- 버튼 active: translateY(2–3px) + 하단 그림자 축소
- 애니메이션 keyframes: `shake`(좌우 -8/7/-5/4px + ±3° 회전, 0.45s ease-in-out — 연속 오답 시 재생되도록 재트리거), `pop`(scale 0→1.25→1, 0.45s), `bounceIn`(translateY 16px·scale .9 → 원위치, 0.4–0.5s), `floaty`(Y 0→-4px, 1.4–1.6s 무한)
- 스피커/현재 내용 듣기 버튼은 TTS 연결 지점(프로토타입에서는 동작 없음)

## State Management
- `screen`: list | question | result | order | orderDone | complete
- question: `selected`(null|0–2), `showWrong`, `hintOpen`, `exampleOpen`
- order: `order`(맞춘 단계 인덱스 배열, 정답만 추가됨), `wrongCard`(마지막 오답 카드), `wrongTick`(흔들림 재트리거용)
- 완료 진행률(2/12, 17%)은 실제 사용자 진행 데이터로 대체
